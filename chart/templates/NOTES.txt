The first complete day of cost data appears the day after install: OpenCost and the bundled
Prometheus start collecting now, and the agent pushes closed UTC days. Until then the pod may
report no data for yesterday; that is expected on a new install and does not mark it unready.
{{- if eq $c.prometheus.bundled.storage.type "emptyDir" }}

The bundled Prometheus keeps its data in an emptyDir: it survives container restarts but not the
pod being rescheduled to another node, which loses the history it holds. Set
prometheus.bundled.storage.type=pvc to keep it (the pod stays Pending if the cluster has no
default StorageClass).
{{- end }}
